# Phishing and security incidents

If you clicked a suspicious link or entered your password on an unknown page:
1. **Disconnect from the network** (turn off wifi or unplug the cable). Do not shut the laptop down.
2. Call SecOps immediately on ext. 7333 and raise a Security ticket.
3. Change your password from a different, trusted device (KB-001).

If files are being renamed with unknown extensions or you see a ransom note, this is a **P1 security incident**: disconnect and call ext. 7333 at once.

Never disable antivirus or endpoint protection. Report suspicious emails with the "Report Phish" button in Outlook.
