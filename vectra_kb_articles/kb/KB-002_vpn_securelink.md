# Connecting to VPN with SecureLink

> Note: kept for reference only.

1. Install SecureLink client v6 from the Software Center.
2. Server address: **vpn.vectralogistics.example**, port 10443.
3. Sign in with your network username and password.
4. If you see "authentication failed", reset your password (KB-001) and retry after 15 minutes.

SecureLink supports Windows, macOS and Linux.
