# Software installation requests and licences

- Standard apps (Chrome, Zoom, Teams, Power BI Desktop) can be installed by anyone from Company Portal.
- Licensed apps (SAP GUI, Tally, AutoCAD) need **manager approval** in the request ticket; App Support installs within 2 business days of approval.
- "Licence expired" on a licensed app: raise a Software ticket; App Support reassigns a licence from the pool, usually same day.
- Update error 0x80070005 means access denied: restart, then retry from Company Portal; do not try to install as local admin.
